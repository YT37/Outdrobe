# Outdrobe - Server

A server for the Outdrobe application.

### VM Management
```bash
# Start VM
./vm-manage.sh start

# Stop VM
./vm-manage.sh stop

# Restart VM
./vm-manage.sh restart

# Check status
./vm-manage.sh status

# View logs
./vm-manage.sh logs

# SSH into VM
./vm-manage.sh ssh

# Update deployment
./vm-manage.sh update
```
